Canelo privacy policy

Canelo is a private assistant used by one family. This page explains how it uses Google data.

What Canelo uses

  • Google Calendar: to read, add and change the family's events and reminders.
  • Google Drive: only files Canelo itself creates, to store documents for the family.
  • Gmail (read only): to find bookings and confirmations, such as flight and hotel emails.

What Canelo never does

  • It never sells, shares or gives Google data to anyone outside the family.
  • It never uses Google data for advertising.
  • It never sends email from Gmail.

Canelo's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
